# Working mockup
Open index.html, or view inside Angular. One check-in, no active checkout/category UI, multi-select event eligibility, ends_at-derived finish, positive capacity, FIFO capacity increases and admin protection. All previous replaced functions remain commented in app.js; originals remain in docs/references. LocalStorage key is separate from the original. Demo records are not database seed. Authorization and QR are still simulations; no business API connected.

Accounts keep a fixed role. Admin can create Organizer accounts and lock/unlock accounts, but cannot change their roles. The preview selector switches between separate sample accounts; it does not modify an account's role.
