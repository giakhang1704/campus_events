# Hợp đồng API Increment 1

Phiên bản triển khai tài khoản: nhánh feature/i1-accounts-rbac. Các mục sự kiện bên dưới là hợp đồng đề xuất cho A05.2, chưa có implementation.

## Quy ước
Base /api, JSON UTF-8, id số nguyên, pagination page bắt đầu 0; size 1..100. Không trả password_hash/token_hash/secret. Lỗi {code,message,fields?}: 400 validation, 401 chưa đăng nhập/hết phiên, 403 trái quyền/CSRF/mật khẩu tạm, 404 không tồn tại, 409 trùng/xung đột/bảo vệ nghiệp vụ. Các lỗi DB không trả SQL hoặc stacktrace cho client. Dữ liệu timestamp khi bổ sung vào API phải dùng ISO 8601 có offset; múi giờ vận hành Asia/Ho_Chi_Minh.

## Xác thực đã chọn
Session opaque ngẫu nhiên 256 bit, chỉ lưu SHA-256 trong auth_sessions. Cookie CAMPUS_SESSION HttpOnly, SameSite=Lax, Path=/api, hết hạn 8 giờ. Mỗi request đối chiếu user ACTIVE, role hiện tại, auth_version, expires_at/revoked_at. Không lưu token trong localStorage/sessionStorage. Khóa/đổi quyền/đổi mật khẩu thu hồi các phiên trong cùng transaction. Đổi mật khẩu yêu cầu đăng nhập lại.

GET /auth/csrf trả {token,headerName}; client lấy token hiện hành trước mỗi thao tác ghi (đặc biệt sau login/logout), rồi gửi X-XSRF-TOKEN cho mọi POST/PATCH (kể cả login/register/logout), đồng thời gửi cookie XSRF-TOKEN. CSRF bảo vệ login/logout. CORS cross-origin mặc định không mở; triển khai FE/API khác host cần reverse proxy cùng origin hoặc thiết kế CORS/cookie phù hợp trước khi dùng. Production HTTPS đặt AUTH_COOKIE_SECURE=true; local HTTP false.

Mật khẩu tối thiểu 8 ký tự, tối đa 72 byte UTF-8, BCrypt cost 12. Email trim/lowercase; MSSV trim/uppercase. Phương án một vai trò hiện hành/tài khoản theo schema hiện tại. Sinh viên tự khai là dữ liệu giả lập, không chứng minh danh tính trường.

## Tài khoản — đã triển khai
| Method | Endpoint | Quyền | Request / Response |
|---|---|---|---|
| GET | /auth/csrf | Public | 200 {token,headerName} |
| POST | /auth/register | Public + CSRF | {fullName,email,password,studentCode,departmentId,studyYear} -> 201 PublicUser; luôn STUDENT |
| POST | /auth/login | Public + CSRF | {email,password} -> 200 PublicUser + session cookie mới; sai/khóa trả cùng nhóm lỗi 401 |
| GET | /auth/me | Đã đăng nhập | 200 PublicUser; tải lại trang phục hồi phiên từ cookie |
| POST | /auth/logout | Đã đăng nhập + CSRF | 204, revoke phiên hiện tại, xóa cookie |
| POST | /auth/password | Đã đăng nhập + CSRF | {currentPassword,newPassword} -> 204, revoke mọi phiên; phải login lại |
| GET | /catalog/departments | Public | [{id,code,name}] |
| GET | /catalog/organization-units | Public | [{id,name}] |
| GET | /admin/users?q=&page=0&size=20 | ADMIN | {items:PublicUser[],page,size,hasNext} |
| POST | /admin/users | ADMIN + CSRF | {fullName,email,temporaryPassword,organizationUnitId,reason} -> 201 ORGANIZER, mustChangePassword=true |
| PATCH | /admin/users/{id}/status | ADMIN + CSRF | {status:ACTIVE/LOCKED,version,reason} -> PublicUser |
| PATCH | /admin/users/{id}/role | ADMIN + CSRF | {role:STUDENT/ORGANIZER/ADMIN,organizationUnitId?,version,reason} -> PublicUser |

PublicUser: {id,fullName,email,role,status,mustChangePassword,version,organizationUnitId,studentCode,departmentId,studyYear}; thông tin không áp dụng là null. Quyền ADMIN không tự bao gồm quyền ORGANIZER.

Không tự khóa/đổi vai trò. Cùng advisory transaction lock serialize mọi thay đổi quản trị; recheck actor trong transaction, giữ Admin ACTIVE cuối cùng. Version cũ -> VERSION_CONFLICT. Demote/khóa organizer có DRAFT hoặc sự kiện chưa kết thúc -> ORGANIZER_HAS_EVENTS; không tự chuyển sự kiện cho người khác. Chuyển sang STUDENT cần hồ sơ đủ; ORGANIZER cần đơn vị hợp lệ. Lịch sử chỉ chụp PublicUser, không chứa hash/token. Mật khẩu tạm chỉ được bàn giao ngoài ứng dụng; mọi API ngoài me/password/logout/csrf/health bị chặn cho đến khi đổi.

## Sự kiện — hợp đồng cho A05.2, chưa triển khai
| Method | Endpoint | Quyền / hành vi |
|---|---|---|
| GET | /events?q=&page=0&size=20 | Đã đăng nhập; danh sách PUBLISHED, tìm title, phân trang |
| GET | /events/{id} | Xem PUBLISHED; chủ sở hữu được xem nháp; không lộ nháp người khác |
| GET | /organizer/events?page=0&size=20 | ORGANIZER; chỉ sự kiện của mình |
| POST | /events | ORGANIZER; tạo DRAFT, organizerId lấy từ phiên |
| PATCH | /events/{id} | ORGANIZER chủ sự kiện, version bắt buộc |
| POST | /events/{id}/publish | ORGANIZER chủ sự kiện; {version}, kiểm tra dữ liệu trước công bố |

Payload tạo/sửa: {title,description,location,organizationUnitId,registrationOpensAt,registrationClosesAt,startsAt,endsAt,capacity,departmentIds:[],studyYears:[],version?}. Các mốc là ví dụ dạng 2026-11-15T08:00:00+07:00. Response thêm id,organizerId,status,publishedAt,version. capacity nguyên dương; không có category/check-out/XLSX. Mở đăng ký < đóng đăng ký <= bắt đầu < kết thúc; nháp vẫn đủ trường cơ bản theo schema. Giới hạn nhiều khoa/năm, rỗng=mọi đối tượng, khoa AND năm. ends_at quyết định kết thúc, không có nút finish.

Các API đăng ký tham gia, FIFO, email thuộc I2; điểm danh/báo cáo/CSV thuộc I3. Việc ghi hợp đồng không đánh dấu các endpoint chưa triển khai là hoàn tất.
